TRAINED MODEL / HELD-OUT EVALUATION

Does learning actually help?

A small ridge regression model predicts dispatch-to-delivery time from distances, nearby robots, workload, and backlog. Dispatch selects the candidate with the lowest predicted cost. The same collision planner serves all policies.

Load the saved experiment to inspect training provenance and results on unseen seeds.

Supervised learning, not reinforcement learning. Completed-job training labels exclude unfinished jobs. Evaluation uses unseen seeds in the same warehouse; it does not establish real-world performance.

UNDER THE HOOD

Coordination you can inspect.

01 · Dispatch

FIFO assigns the first available robot. Nearest dispatch uses breadth-first search to measure reachable pickup distance around obstacles.

02 · Plan

Space-time A* searches positions and future ticks. Reservations prevent shared cells and head-on swaps. Planning priority rotates each tick.

03 · Replan

Robots execute one step, then plan again. Disabled robots stay put. Bounded planning can still stall; collision avoidance does not guarantee eventual delivery.

A discrete fleet coordination simulator. Includes supervised dispatch learning. No physical dynamics, sensors, battery model, or real robot deployment.
